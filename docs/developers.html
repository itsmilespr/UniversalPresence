Build your own

Universal Presence is a .NET 8 WinForms app with no NuGet dependencies. You can fork it, change the presence layout, add players, or write a plugin without touching the core.

1. Build from source

git clone https://github.com/itsmilespr/UniversalPresence.git
cd UniversalPresence
./.dotnet/dotnet build -c Debug
./.dotnet/dotnet publish UniversalPresence.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:DebugType=None -p:DebugSymbols=false -p:PublishDir=publish/

Requirements: .NET 8 SDK and Windows 10/11 x64. The project uses Windows SMTC and Discord IPC, so it cannot run on macOS or Linux.

2. Create a plugin

Plugins are .NET assemblies loaded from %LOCALAPPDATA%\UniversalPresence\plugins. Enable PluginsEnabled in config.json, then drop your DLL there.

using UniversalPresence.Media;
using UniversalPresence.Plugins;

public sealed class MyPlugin : IUniversalPresencePlugin
{
    public string Name => "My plugin";

    public void Initialize(PluginContext context)
    {
        context.Log("Plugin started");
    }

    public void OnTrackChanged(MediaSnapshot? snapshot)
    {
        if (snapshot is { IsActive: true })
        {
            // snapshot.Title, Artist, Album, PlayerName, AppUserModelId...
        }
    }
}

Target framework: net8.0-windows. Reference the main project or copy the Plugins and Media namespaces. Plugins receive track changes after the app builds the activity; keep them fast and never block the UI thread.

MediaSnapshot fields

AppUserModelId, PlayerName, PlayerExecutable, Title, Artist, Album, AlbumArtist, Status, Position, Duration, Artwork, PublicArtworkUrl, ProgramIconUrl, PlayCount, IsActive.

3. Change the presence layout

Use DetailsTemplate, StateTemplate and LargeTextTemplate in settings. Placeholders: {title}, {artist}, {album}, {player}, {status}. For deeper changes, edit Core/ActivityFactory.cs.

4. Profiles

Profiles are stored in %APPDATA%\UniversalPresence\profiles\{name}.json. The default profile is config.json. Use the settings window or --profile name from the CLI.

5. Self-test

UniversalPresence.exe --self-test

Runs in-process checks for localization, config roundtrip, secret protection and activity generation. Use it before sending a pull request.

6. Contribute

Open an issue or pull request on GitHub. Keep the app free of player whitelists: every SMTC session must remain detectable. Run --self-test and --test --dry-run before submitting.
