Features

Everything it does, asking nothing of you

No accounts, no tokens to paste and no list of supported players: if Windows exposes it, it shows.

No whitelists

Any app Windows exposes via SMTC works. You do not have to wait for your player to be added.

Real cover art

Takes the cover from the player itself; if it does not provide one, it looks it up on iTunes and Deezer in parallel.

Drift-free bar

Absolute timestamps and re-anchoring on pause. The bar tracks the audio, even when skipping tracks.

Instant updates

Reacts to Windows events and publishes on a separate thread: Discord's rate limit blocks nothing.

×N counter

Detects when you repeat the same track and shows it in the status: ×2, ×3, ×4…

Player icon

Extracted at 256 px from the player's own .exe and cached: sharp and not repeated on every track.

Private by design

Everything happens on your PC. No account, no telemetry and no own servers: only Discord's local IPC.

A single .exe

Self-contained: no need to install .NET. Starts with Windows if you want, from the settings.

How it works

Three steps and you are done

No need to create a Discord application or paste tokens: the id is included.

01

Download and open it

A single UniversalPresence.exe. It stays in the system tray, no annoying windows.

02

Play music

In any Windows player. The cover, the artist and the bar appear on their own.

03

Check your Discord

With Discord open, your status shows the track instantly. If you close it, it reconnects on its own.

Built to need no setup. On launch it detects the player, resolves the icon and connects to Discord. Settings are optional: they live in the tray menu.

FAQ

Common questions

Do I need an account or to configure Discord?

No. The app ships its own Discord application id and connects over the local channel (IPC) when Discord is open. No login, no token and no need to create an application in the developer portal.

Which players work?

All those that expose their session on Windows: Spotify, foobar2000 (with Gatefold), VLC, Apple Music, MusicBee, Windows Media Player, TIDAL… Browsers are excluded by default so a YouTube tab does not show up as music, and you can remove that exclusion.

Why does Windows SmartScreen warn on open?

Because the executable is not signed with a paid certificate. Normal for small projects: click “More info” → “Run anyway”. The code is open and you can build it yourself.

Where is my configuration stored?

Always on your machine: %APPDATA%\UniversalPresence\config.json. Logs and cached covers live in %LOCALAPPDATA%\UniversalPresence. Nothing is sent to any project server.

How do I uninstall it?

Exit from the tray menu, delete the .exe and, if you want, the two folders above. Starting with Windows can be disabled beforehand from Settings.

Does it work on macOS or Linux?

No: it uses Windows media APIs (SMTC) and Discord's IPC channel for Windows. Built and tested for 64-bit Windows 10 and 11.

Can I build or modify it?

Yes. The project is .NET 8 (WinForms) with no NuGet dependencies and is published under the MIT license. Build instructions and technical docs are in the repository.

Does it publish what I see in the browser?

Only if you allow it: Brave, Chrome, Edge, Firefox, Opera and Vivaldi are ignored by default, so a YouTube tab is not published.
